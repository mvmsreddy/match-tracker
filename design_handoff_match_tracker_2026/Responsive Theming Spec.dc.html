What's blocking day/night and big screens today

Fixed 31 Jul · was: two competing dark themes

Navy identity lives outside the token system

src/index.css pins the shipped look — --bg: #14293D, lime --accent: #C6E23D — at :root, so it never flips. Meanwhile app-tailwind.css's .dark block is near-black (0 0% 4%) with a blue primary. Two dark palettes, one screen.

Fixed 31 Jul · was: light mode untested

Legacy classes hard-code dark values

Light --app-* tokens exist, but any screen still using .panel, .field, .drawer-*, .history-empty or .role-overlay-* stays dark when the toggle flips — light text on light ground.

Gap · no large-screen layout

The desktop rail is dead code

.mt-rail and .mt-tabbar are fully written but gated behind [data-theme="navy"], which ThemeContext no longer sets. On a laptop every user gets the phone drawer and a single narrow column.

Gap · fixed widths fight the viewport

680 px caps and full-height locks

.wrap/.panel cap at 680 px while app pages use max-w-7xl; .root sets height: 100dvh; overflow: hidden, and the bracket grid uses absolutely-positioned 236 px cards. Three different width philosophies.

Gap · outdoor legibility

10 px labels and thin muted text

Eyebrows and table heads are text-[10px] on muted-foreground. Indoors that's fine; in daylight on a phone it disappears. Point-outcome colour is also the only carrier of win/loss meaning in several places.

Cleanup · naming

Three token namespaces, one palette

--bg/--accent (index.css), --app-* (app-tailwind) and --color-tt-* (tracker-tailwind) describe the same roles. Also: --font-tt-mono resolves to IBM Plex Sans, so "mono" labels aren't monospaced and numbers don't align.

02 · Theme architecture

One token layer, three tiers, resolved from the sun

Collapse all three namespaces into --app-* and keep --bg/--color-tt-* only as aliases during migration. Tier is a single attribute on <html>.

data-tier="day"

Day

Sunrise+30 min → sunset−45 min. Warm paper ground, navy ink, lime reserved for fills. Default outdoors.

data-tier="night"

Night

Sunset−45 min → sunrise+30 min. Today's shipped navy, unchanged in hue so the brand still reads.

data-tier="glare"

Glare

Manual only — one tap from the scorebar. Pure white, 7:1 minimum, heavier weights, no muted greys.

src/context/ThemeContext.jsx — replace the boolean toggle
// preference: 'auto' | 'day' | 'night' | 'glare'   (localStorage 'tt-theme')
// resolved tier is what lands on <html data-tier>

const PRE_DAWN = 30, PRE_DUSK = 45;            // minutes of margin

function resolveTier(pref, sun, now = new Date()) {
  if (pref !== 'auto') return pref;
  if (!sun) return matchMedia('(prefers-color-scheme: dark)').matches ? 'night' : 'day';
  const t = now.getTime();
  const from = sun.sunrise + PRE_DAWN  * 60000;
  const to   = sun.sunset  - PRE_DUSK  * 60000;
  return t >= from && t < to ? 'day' : 'night';
}

// sun comes from the Open-Meteo call src/lib/weather.js already makes —
// add `daily=sunrise,sunset`, cache { lat, lon, sunrise, sunset, day }
// in localStorage, refetch once per calendar day. No location → media query.

useEffect(() => {
  const apply = () => document.documentElement.dataset.tier = resolveTier(pref, sun);
  apply();
  const id = setInterval(apply, 5 * 60 * 1000);        // catch dusk mid-match
  document.addEventListener('visibilitychange', apply); // and after a lock
  return () => { clearInterval(id); document.removeEventListener('visibilitychange', apply); };
}, [pref, sun]);

Rules: never flip tier mid-interaction — if a wizard step or modal is open, defer to the next idle render. Always transition background-color and color over 240 ms so an auto-switch at dusk doesn't feel like a crash. Keep the manual control 3-state (Auto / Day / Night) plus a separate Glare switch — the current binary toggle can't express "auto".

06 · Courtside rules

Non-negotiables for logging a live point

Targets

Wizard chips 56 px min height (up from 50), 8 px gaps so a sweaty thumb can't hit two. Nav/toolbar buttons stay 44 px. Destructive actions never adjacent to an outcome chip.

Reach

Bottom 45% of the phone viewport holds every per-point control; the scorebar and match metadata sit up top where they're read, not tapped. Undo lives bottom-left, permanently.

Glare

Glare tier is one tap from the scorebar, not buried in the drawer — it's needed when the sun turns, mid-match. It also forces 100% brightness where the platform allows and disables all muted greys.

Screen & battery

useWakeLock already exists — surface its state as a small mono chip in the scorebar so the user knows the screen is being held. Night tier is the battery-cheap default after dusk.

Meaning without colour

W/L, serve indicator, winner/error rows all carry a letter or glyph alongside hue. Passes both colour-blindness and washed-out-in-sun conditions.

Safe areas

Bottom bar pads with env(safe-area-inset-bottom) (already in .mt-tabbar); drop .root { overflow: hidden } so Android keyboards can't clip the wizard.
