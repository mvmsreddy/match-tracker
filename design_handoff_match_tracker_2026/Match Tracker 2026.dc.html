What changed vs the old screens

Hairline 4 px boxes → 24–28 px soft cards on tinted ground. Uppercase mono micro-labels → sentence-case medium text. Dense stat tables → a few big numbers with an inline sparkline. Tabs → pill segments. Drawer-first nav → floating bottom bar.

Still intact

Every field and action from the real code: scorebar with set boxes and break-point badge, the 4-step wizard, undo, wake-lock indicator, streak + freeze tokens, weekly rings, recent sessions with W/L letters. Nothing was removed to make it look tidy.

Note for the dev — glyphs are stand-ins

Ship the lucide-react icons the code already imports, not these characters: LayoutDashboard ▤, Activity ◈, History ◷, Trophy ♛, Dumbbell ◇, Droplet ◉, Bell ◔, Undo2 ↩, MoreHorizontal •••, plus the wake-lock ⦿. Only the brand mark is a real asset (scripts-tmp/logo.svg).

Day & night still auto

Both directions ship both tiers — 1a is the day face, 1b the night face. If you like both, that IS the system: 1a from sunrise, 1b after dusk, one token layer.
